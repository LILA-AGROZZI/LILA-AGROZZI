📶 Modo Offline y Sincronización

La app funciona 100% sin conexión a internet: cada registro se guarda al instante en este dispositivo. Al recuperar señal, todo lo pendiente se envía solo a SharePoint mediante Power Automate (configuración abajo) — no hay que hacer nada manualmente.

🔐 Administración y Permisos

Las modificaciones de líneas y componentes requieren autenticación. Solo usuarios autorizados pueden realizar cambios.

💾 Respaldo y Restauración

Todas las exportaciones a Excel — el registro por actividad, el reporte y el respaldo completo — se guardan en archivos fijos que se van actualizando (no se crea un archivo nuevo cada vez), con las fotos de evidencia incrustadas y todas las hojas con filtro (autofiltro) activado para que puedas filtrar por Línea, Fecha, Operador, etc. directamente en Excel. Todo se guarda automáticamente en este dispositivo; el respaldo Excel es una copia extra por seguridad.

📊 Respaldo automático al finalizar cada actividad
Al terminar una actividad, la fila se agrega dentro del mismo archivo acumulativo (LILA_Registro_Actividades.xlsx, con hojas "Actividades", "Componentes y Observaciones", "Resumen Cumplimiento", "Fotos Evidencia" y "Mapa de Calor y Gráfico" — con el mismo formato exacto del reporte Mespack por actividad, y con filtro/agrupación para revisar cada actividad por separado—) guardado en la carpeta que elijas abajo. Ya no se crea una carpeta ni un archivo nuevo por cada actividad.
📁 Carpeta donde guardar los Excel (imprescindible para que se acumulen en un solo archivo)
Elige una carpeta una sola vez. Desde ahí en adelante, los 3 archivos siguientes se guardan y actualizan siempre ahí, sin volver a preguntar ni duplicarse: LILA_Registro_Actividades.xlsx (crece fila a fila con cada actividad), LILA_Reporte.xlsx (botón "Exportar Excel") y LILA_Respaldo_Completo.xlsx (botón "Descargar Respaldo Excel Completo").
Sin carpeta configurada — se usará la carpeta de Descargas del dispositivo.
⚠️ La carpeta persistente está disponible en Chrome / Edge (computador o Android). En otros navegadores, o si no eliges carpeta, cada exportación se descarga como un archivo nuevo con fecha en el nombre (no se puede acumular en el mismo archivo sin esta función del navegador).
📥 Descargar Registro de Actividades (por seguridad)
Descarga ahora mismo una copia completa y actualizada del LILA_Registro_Actividades.xlsx con todas las actividades guardadas hasta hoy. Sirve como respaldo extra para guardar donde quieras (correo, nube, USB) y, si cambias de dispositivo o reinstalas la app, poder recuperar todo el historial. El archivo de la carpeta elegida arriba se sigue alimentando solo con cada actividad; este botón es una copia manual adicional cuando la necesites.
✏️ El Excel se puede editar libremente: puedes agregar columnas, notas, copiar y pegar información, o crear hojas nuevas — la app no las borra. Para que nada se pierda ni se desordene cuando se agreguen nuevas actividades automáticamente: agrega tus columnas después de las últimas de cada hoja (no en medio) y, si prefieres, usa una hoja nueva aparte para tus propias notas.
🆕 Reiniciar Excel desde Cero genera un archivo nuevo y en blanco (mismos encabezados, sin la información anterior): lo descarga y, si tienes una carpeta de respaldo automático configurada, también reemplaza ahí el LILA_Registro_Actividades.xlsx — desde ese momento el archivo se sigue alimentando solo, automáticamente, con cada actividad que finalices. Requiere iniciar sesión de administrador. El historial guardado dentro de la app no se borra.
📦 Excel Antiguos (Archivados)
Toda la información siempre se puede recuperar completa con el botón "📥 Descargar Registro de Actividades" de arriba (junta todo el historial guardado en la app, sin límite). Además, el archivo acumulado que se guarda solo en la carpeta de respaldo tiene un límite de tamaño (20 MB): al llegar a ese límite, se archiva con fecha en el nombre y se abre uno nuevo automáticamente, para que nunca crezca demasiado. Aquí puedes ver y descargar esos archivos antiguos sin tener que buscarlos manualmente en la carpeta.
💡 El registro automático (por actividad) queda siempre sincronizado con el Mapa de Calor de la app: usa las mismas observaciones y anomalías registradas. El botón "Descargar Respaldo Excel Completo" además actualiza un archivo consolidado con el historial completo.
🔀 ¿Trabajas desde dos computadores? Puedes seleccionar los dos archivos "Respaldo Excel Completo" (uno de cada computador) juntos en "📂 Restaurar desde Respaldo" — la app combina la información de ambos sin perder nada (no borra lo que ya tienes; agrega lo que falte). Debe ser el archivo generado por "📊 Descargar Respaldo Excel Completo" (no el LILA_Registro_Actividades.xlsx del respaldo automático, que no contiene la información necesaria para restaurar).
